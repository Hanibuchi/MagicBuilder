# Magic Builder

**呪文を並べて撃つ、呪文配置ゲーム**

Noitaのユニークなスタッフシステムにインスパイアされた、呪文を自由に組み合わせて敵を倒すiOSゲームです。

## ダウンロード

[![App Store](https://img.shields.io/badge/App_Store-0D96F6?style=for-the-badge&logo=app-store&logoColor=white)](https://apps.apple.com/app/id6762497415)

## ゲーム概要

呪文をドラッグして発射し、敵を倒すゲームです。80種類以上の呪文を組み合わせることで、様々な攻撃戦略を作り出せます。

### ステージ

- **6つの島**: 森、砂漠、火山、氷山、宮殿、空島
- **各島6ステージ**: 合計36ステージ
- **2種類のステージ形式**:
  - **パズル**: 使用できる呪文が制限される
  - **ラッシュ**: 装備した道具を持ち込める
- **エンドレスステージ**: 練習用

### 呪文システム

80種類以上の呪文を4カテゴリで分類:

| カテゴリ | 色 | 説明 |
|----------|-----|------|
| 攻撃 | オレンジ | 単体・範囲・多段ヒットの攻撃呪文 |
| 修飾 | 青 | 他の呪文を強化・変化させる |
| 分岐 | 緑 | 呪文の発射方向や挙動を変える |
| その他 | 黄 | 特殊効果を持つ呪文 |

**ダメージ属性**: 通常 / 木 / 水 / 温度 / 回復 / ノックバック

### スタッフ

島ごとに1本、合計6本のスタッフが登場。各スタッフは固定の呪文スロットを持ちます。

## 技術情報

- **エンジン**: Unity
- **プラットフォーム**: iOS (iPhone / iPad)
- **開発期間**: 約6ヶ月
- **開発者**: Hanibuchi Kouto

### アーキテクチャのポイント

分岐呪文の処理で指数関数的に計算が増大する問題を、キャッシュを活用して解決しています。
呪文スケジューラー ([SpellScheduler.cs](Assets/Scripts/Spells/SpellScheduler.cs)) が呪文の実行順序と
クールダウン計算を管理し、複雑な呪文チェーンを効率的に処理します。
